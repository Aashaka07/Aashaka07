`SystemVerilog` `Verilog` `Python` `Verilator` `Yosys` `OpenLane` `SKY130`

Currently developing a 4×4 weight-stationary INT8 systolic array for matrix-multiplication acceleration, with a focus on input deskew buffers, a 128-bit packed weight bus, Python-based golden-reference verification, and an open-source SKY130 ASIC implementation flow.
